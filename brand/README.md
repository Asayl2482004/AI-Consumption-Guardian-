# هوية شعار قدّر · Qadr logo

شعار مبني بالكامل على رموز النموذج الحالي. **لم يُعدَّل النموذج ولا أي واجهة.**

## الفكرة

قدّر يقرأ نمط الشراء ويثبّت خطًّا عند الكمية المعتادة. العلامة هي ذلك الخط:
ثلاثة أعمدة تمثّل نمط الشراء — اثنان عند الخط وواحد يتجاوزه.
الاسم «قدّر» يعني التقدير والقياس.

## قواعد

- الاسم يُكتب دائمًا بالشدّة: **قدّر** — وبالإنجليزية **Qadr**، وليس QADRA.
- مساحة أمان لا تقل عن نصف عرض العلامة.
- فوق الأخضر استخدم النسخة المعكوسة — لا مربّع أخضر داخل أخضر.
- تحت ‎32px استخدم `qadr-favicon.svg`؛ لا تُصغّر علامة الـ‎64.
- أصغر عرض للتركيبة الأفقية: ‎140px.
- بدون ظل أو تدرّج أو دوران. اللون التحذيري `#b7791f` لغة حالة داخل المنتج، وليس لون شعار.
